# Scrum Framework Poster
This poster gives you an overview of the Scrum Framework. The poster is up to date with the [2020 release of the Scrum Guide](https://scrumguides.org).
This newest version of the Scrum Framework poster displays the Scrum Framework on top of empiricism and the Scrum values. Scrum without the underlying empirical approach leads to misguided implementation. The Scrum values are key to the use of Scrum.

There are a couple of different formats/files available in the release. For digital use and for printing. 

# Miro template not updated yet
As of yet we do not have Miro or Mural templates of this framework version yet. Let us know if you would like to contribute on that (info@scrumfacilitators.com).
